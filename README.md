# When Did Kenya's Debt Become a Problem? A Sustainability Analysis (1980-2024)

This project examines Kenya's public debt trajectory from 1980 to 2024, comparing key debt indicators against IMF and World Bank sustainability thresholds to identify when Kenya's debt became unsustainable and what the early warning signs were.

## Tools
Python, pandas, matplotlib, seaborn, Streamlit

## Data source
World Bank World Development Indicators

## Project structure
- data/ — raw and cleaned datasets
- notebooks/ — exploratory analysis
- src/ — data cleaning and fetching scripts
- dashboard/ — interactive Streamlit app
